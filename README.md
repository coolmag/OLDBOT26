# Aurora AI DJ Bot

Aurora AI DJ — это многофункциональный музыкальный Telegram-бот, созданный на Python с использованием FastAPI и `python-telegram-bot`. Он сочетает в себе функции радио, умного ассистента и музыкального плеера, предоставляя пользователям уникальный интерактивный опыт.

## 🎵 Ключевые возможности

- **🤖 Умный AI-диджей и собеседник:**
  - Использует передовые генеративные AI-модели (Google Gemma/Gemini) для обработки запросов на естественном языке.
  - Может генерировать остроумные объявления и подводки к трекам, как настоящий радиоведущий.
  - Поддерживает различные "личности" AI (например, `токсик`, `стендап-комик`, `эксперт`), которые администратор может переключать через команду `/admin`.

- **📻 Режим "Радио":**
  - Воспроизводит музыку в непрерывном режиме 24/7.
  - Автоматически меняет музыкальный жанр каждый час, объявляя об этом голосом AI-диджея.
  - Пользователи могут принудительно установить жанр (`/set_genre`, только для админов) или запустить волну по трекам одного исполнителя (`/artist`).

- **🔎 Гибкий поиск музыки:**
  - **`/play <название>`:** Находит и отправляет в чат конкретный трек.
  - **`/artist <исполнитель>`:** Включает режим воспроизведения треков только указанного исполнителя.
  - **`/radio <жанр>`:** Запускает радиоволну по указанному жанру.
  - **Распознавание голосовых команд:** Пользователи могут просто наговорить свой запрос голосовым сообщением.

- **🌐 Отказоустойчивая система загрузки:**
  - Использует многоуровневую систему для поиска музыки: сначала метаданные ищутся через **YTMusic**, затем аудио скачивается с **SoundCloud**. В качестве резервного варианта используется **yt-dlp**.

- **✨ Интерактивный веб-плеер:**
  - В комплекте идет легковесный (<15 КБ) веб-плеер в ретро-стиле, доступный по ссылке.
  - Отображает текущий трек, обложку и позволяет слушать эфир прямо в браузере.

- **🎮 Игровой режим:**
  - Включает игру "Угадай мелодию" (`/quiz`), добавляя интерактивности в чат.

## 🛠️ Технологический стек

- **Бэкенд:** Python 3.11+, FastAPI, Uvicorn
- **Telegram Bot API:** `python-telegram-bot`
- **AI:** Google Gemma & Gemini через OpenRouter API
- **Аудио:** `ffmpeg` для обработки звука
- **Развертывание:** Docker, `railway.json` для деплоя на Railway
